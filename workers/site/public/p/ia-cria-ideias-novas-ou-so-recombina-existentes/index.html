IA cria ideias novas ou só recombina existentes?

Criada com Gemini

Debate técnico ganhou força após startup Harmonic anunciar que IA resolveu problema matemático histórico de Paul Erdős; comunidade científica divide-se: IA inova genuinamente ou apenas conecta ideias já conhecidas.​

O caso Harmonic-Aristotle:

  • IA (com GPT-5.2 Pro) resolveu 10 problemas de Erdős​

  • Pesquisadores descobriram: soluções já existiam em artigos e livros acadêmicos antigos​

  • IA não criou resposta nova, mas navegou milhares de dados conectando trabalhos esquecidos​

Divisão entre especialistas:

  • Visão pessimista: IA recombina; humanos criam (Terence Tao)​

  • Visão pragmática: IA útil para pesquisa acelerada, não "gênio original"​

  • Visão otimista: Dra. Derya Ununtmaz: "IA sugere hipóteses não consideradas por mim"​

  • Estudo Science Advances: IA melhora criatividade individual mas reduz diversidade coletiva​​

Por que isso importa

Consenso emerge: IA não cria do nada, mas amplifica e acelera pensamento humano. Para pesquisadores brasileiros, significa IA é ferramenta de produtividade, não substituição.

Openwork: agente IA open-source que roda localmente

Accomplish.ai lançou Openwork, agente IA open-source que executa tarefas direto no seu computador — automatizando organização de arquivos, redação, workflows repetitivos com controle total e sem enviar dados à nuvem.​

Diferenciais técnicos:

  • Roda localmente: arquivos ficam no seu Mac, você controla permissões​

  • Qualquer modelo: use OpenAI, Anthropic ou qualquer API compatível​

  • 4x mais rápido que Claude Cowork; muito mais eficiente em tokens​

  • Mais seguro: não usa sessão principal do navegador; prompt injections limitados​

  • Open-source MIT: código público no GitHub, modificável​

Funcionalidades:

  • Organizar/renomear arquivos por conteúdo ou regras​

  • Escrever, resumir, reescrever documentos​

  • Criar entradas de calendário a partir de notas​

  • Integração com Notion, Google Drive, Dropbox (via APIs locais)​

  • Salvar workflows repetitivos como "skills" reutilizáveis​​

Por que isso importa

Marca inflexão: agentes IA deixam de ser serviços cloud para serem ferramentas de desktop controladas pelo usuário.

OpenAI liderou maior aporte individual em rodada seed de US$ 252 milhões para Merge Labs, startup de interface cérebro-computador cofundada por Sam Altman.​

Use o ChatGPT Translate além do básico

O concorrente da ferramenta do Google permite usar prompts para editar o texto após a tradução.

O potencial da ferramenta vai além do que é mostrado na interface inicial. Siga o tutorial abaixo para entender mais.

  1. Acesse o ChatGPT Translate

  2. Digite ou cole o texto que quer ver traduzido

  3. Escolha a língua para a qual quer traduzir

  4. Clique em um dos botões abaixo das caixas de texto para definir o tom

  5. Para conhecer todos os tons, cole esse prompt após a tradução. Ele vai te mostrar vários outros exemplos de tons

    1. Quais os tons possíveis para traduções?

  6. Copie o prompt inicial do chat, e inclua os tons que quer usar.

Não existe uma lista fechada ou “oficial” de tons para tradição.

Também é possível combinar tons (ex.: formal + técnico, neutro + jornalístico) ou pedir variação regional (ex.: português formal — Brasil vs. Portugal, espanhol — América Latina vs. Espanha).

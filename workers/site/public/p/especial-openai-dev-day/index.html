Apps SDK: o ChatGPT com hub de comunicação

O Apps SDK transforma o ChatGPT em uma plataforma onde aplicativos vivem dentro das conversas, em vez de existirem como entidades separadas.

Construído sobre o protocolo Model Context Protocol (MCP), o SDK permite que desenvolvedores criem aplicações que funcionam nativamente dentro do ChatGPT, eliminando a necessidade de alternar entre diferentes interfaces.

Os usuários podem agora solicitar ao Canva a criação de designs, pedir ao Zillow listagens de imóveis ou usar o Spotify para música, tudo sem sair da conversa e com monetização planejada através do novo Agentic Commerce Protocol.

AgentKit: construção visual de workflows

O AgentKit representa a resposta da OpenAI à complexidade de criar agentes empresariais, oferecendo uma suíte integrada que inclui Agent Builder (canvas visual para workflows multi-agentes), Connector Registry (hub centralizado para administradores) e ChatKit (interface de chat incorporável).

A ferramenta permite arrastar e soltar componentes para criar fluxos de trabalho sofisticados, com versionamento completo, testes inline e avaliação automatizada.

Em demonstrações ao vivo, agentes foram construídos em menos de oito minutos, prontos para executar tarefas complexas.

O sistema compete diretamente com plataformas como Zapier e n8n, mas oferece integração nativa com os modelos GPT-5 e capacidades avançadas de rastreamento e governança empresarial.

Codex: novidades do assistente de programação

O Codex, assistente de programação da OpenAI, foi oficialmente lançado para uso público com recursos expandidos.

A nova versão inclui integração com Slack (basta marcar @Codex para delegar tarefas), extensão para IDEs como Visual Studio Code e Cursor, e um SDK para incorporar capacidades de codificação em workflows personalizados.

O sistema agora oferece handoff contínuo entre ambientes locais e na nuvem, permitindo que desenvolvedores iniciem tarefas localmente e as deleguem para execução assíncrona sem perder contexto.

Com revisões automáticas de pull requests no GitHub e uma interface de linha de comando completamente redesenhada, o Codex se tornou integral ao desenvolvimento na própria OpenAI, onde engenheiros fazem merge de mais de 70% dos pull requests.

Sora 2: agora disponível via API

O modelo de geração de vídeo da OpenAI Sora 2 produz vídeos de até 90 segundos em resolução 4K com áudio espacial sincronizado, incluindo diálogos e efeitos sonoros.

A API suporta controles cinematográficos avançados, simulação física precisa e o recurso "Cameo" que permite incorporar a semelhança do usuário mediante consentimento.

Embora o acesso público direto ainda não esteja disponível, desenvolvedores podem acessar através da prévia do Azure OpenAI para empresas ou provedores terceirizados como CometAPI e Replicate.

________________________

GPT-5 Pro: agora disponível via API

O GPT-5 Pro, versão mais avançada do modelo de raciocínio da OpenAI, foi disponibilizado via API com preços competitivos de US$ 1,25 por milhão de tokens de entrada e US$ 10 por milhão de tokens de saída.

O modelo oferece capacidades de raciocínio paralelo no tempo de teste, contexto de até 272.000 tokens de entrada e 128.000 tokens de saída, além de desconto de 90% em tokens em cache utilizados recentemente.

A API suporta três variantes (gpt-5, gpt-5-mini, gpt-5-nano) para diferentes casos de uso e orçamentos, com a versão mini custando apenas US$ 0,25/US$ 2,00 por milhão de tokens.

________________________

Modelos Mini: para otimização de custos

A OpenAI introduziu dois novos modelos otimizados para custo e eficiência: o gpt-realtime-mini para geração de voz em tempo real com 70% de redução nos custos comparados às versões anteriores e o gpt-image-1-mini para geração e interpretação de imagens.

Estes modelos fazem parte da estratégia da empresa de democratizar acesso às capacidades avançadas de IA, oferecendo alternativas mais baratas sem sacrificar significativamente a qualidade.

O modelo de voz suporta interações naturais e pode se tornar uma forma primária de comunicação com tecnologia, enquanto o modelo de imagem permite processamento de screenshots, fotos e criação de conteúdo visual a custos muito reduzidos para aplicações de alto volume.

Parceria AMD: 6 GW de poder computacional

Em um movimento estratégico, a OpenAI anunciou uma parceria de vários anos com a AMD para implantação de 6 gigawatts de poder computacional, começando com 1 GW dos próximos chips AMD Instinct MI450 no segundo semestre de 2026.

O acordo inclui uma opção para a OpenAI adquirir até 160 milhões de ações da AMD a US$ 0,01 cada, representando potencialmente 10% de propriedade da empresa se certas metas forem atingidas.

A AMD espera "dezenas de bilhões" em receita do acordo, e as ações da empresa subiram 23,7% após o anúncio.

Esta parceria complementa os compromissos anteriores da OpenAI de 10GW com a Nvidia, elevando seu total planejado de infraestrutura para 23GW através de múltiplos fornecedores.

Criada com Gemini

OpenAI anunciou o OpenAI Grove, um programa dedicado a indivíduos nos estágios iniciais de sua jornada empreendedora em IA.

O que oferece:

  • Cinco semanas de programação, com duas em São Francisco

  • Mentorias de líderes técnicos da OpenAI e oportunidades de construção em conjunto

  • Possibilidade de levantar capital ou prosseguir por outros caminhos

  • Inscrições até 12 de janeiro

  • 4-6 horas semanais de trabalho, com sessões presenciais obrigatórias na primeira e última semana

  • Aceita grupos de aplicantes

Porque isso importa:

Para fundadores brasileiros interessados em tecnologia, representa uma oportunidade rara de mentoria direta com pesquisadores do principal laboratório de IA mundial.

Claude Code fez em 1 hora o que Google levou um ano

Engenheira sênior da Google relata que Claude Code da Anthropic gerou um sistema completo de orquestração de agentes distribuídos em apenas uma hora, um problema que seu time vinha desenvolvendo desde 2024.

O que aconteceu:

  • Jaana Dogan, Principal Engineer da Google, testou Claude Code com um problema de três parágrafos apenas​

  • Sistema gerou resultado funcional em uma hora, comparável ao trabalho de um ano do time Google​

  • Resultado não é perfeito mas demonstra capacidade impressionante de IA para programação​

  • Google só permite uso de Claude Code em projetos open-source, não internos​​

Por que isso importa

Demonstra que ferramentas como Claude Code podem comprimir ciclos de desenvolvimento, reduzindo custos.

O reconhecimento público de uma engenheira sênior do Google sobre superioridade de um concorrente também reflete humildade técnica rara na indústria.

OBNext: IA brasileira detecta câncer de mama em tempo real

Healthtech de Anápolis criou dispositivo portátil que usa IA para analisar câncer de mama durante a cirurgia, eliminando espera de até uma semana por resultados.​

Como funciona:

  • Marcador fluorescente aplicado no paciente antes da cirurgia​

  • Dispositivo OBNext cria "gêmeo digital" da amostra em tempo real​

  • Cores indicam situação: verde (tecido saudável) e vermelho (câncer)​​

Impacto prático:

  • Reduz tempo de espera: atualmente leva 30-60 minutos em hospitais com patologista ou 5-7 dias em cidades menores​​

  • Diminui custo: elimina dependência de laboratórios externos​

  • Evita segunda cirurgia: se margem ficar comprometida, cirurgião ajusta no mesmo procedimento​

Porque isso importa:

Representa inovação médica brasileira de impacto global. Resolve problema real do SUS: falta de patologistas em cidades pequenas e médias. Pacientes poderão ter cirurgias mais precisas sem se deslocar para grandes centros.

Primeiros passos no Claude Code

  1. Preparar o ambiente

    • Baixe o Node.js 

    • Rode o instalador

      • Em Tools for Native Modules, selecione Automatically install the necessary tools

    • Crie uma conta gratuita na Anthropic em claude.ai

    • Opcional: Gere uma chave de API no Console da Anthropic para uso avançado​​

  2. Instalar o Claude Code

    • Abra o terminal (ou PowerShell no Windows)

    • Para macOS/Linux/WSL:

      • curl -fsSL https://claude.ai/install.sh | bash

    • Para Windows PowerShell:

      • irm https://claude.ai/install.ps1 | iex

    • Para Windows CMD:

      • curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd.​

  3. Autenticar a conta

    • Digite claude no terminal para iniciar.

    • Escolha login via OAuth com sua conta claude.ai (opção recomendada).

    • Autorize o acesso quando redirecionado ao navegador.​​

  4. Configurar um projeto

    • Navegue para o diretório do projeto: cd /caminho/para/seu/projeto.

    • Inicie o Claude Code: claude.​

  5. Executar o primeiro comando

    • Digite uma tarefa simples: "Adicione uma função hello world no arquivo main.js".

    • Revise as mudanças propostas (diff mostrado no terminal).

    • Confirme com "y" para aplicar ou edite manualmente.​​

  6. Explorar comandos básicos

    • /help: Veja todos os comandos disponíveis.

    • /clear: Limpe o histórico da conversa.

    • /init: Crie um arquivo CLAUDE.md com resumo do projeto para contexto persistente.​

# Filtros do rclone bisync do Google Drive (#12356). Mudar este arquivo exige
# rodar o bisync uma vez com --resync (o rclone guarda o hash dos filtros).
# O script passa --ignore-case: os padroes casam sem diferenciar maiusculas,
# como o skip_file do OneDrive (#12357).
#
# Globais (Drive inteiro): lixo de editor, temporarios e WAL/SHM de SQLite (#12357).
# O filtro do bisync de data/ (gdrive-data-bisync-filters.txt, #12478) repete
# estas linhas (test/data-sync-exclusions-12357.test.ts trava).
- ~*
- .~*
- *.tmp
- *.swp
- *.partial
- *.db-shm
- *.db-wal
- *.sqlite-shm
- *.sqlite-wal
- *.sqlite3-shm
- *.sqlite3-wal
- *safeBackup*
- desktop.ini
- .DS_Store
- Thumbs.db

# node_modules: .git/objects fica no sync (decisao do editor, 08/11/2026).

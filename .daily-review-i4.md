Em `scripts/apply-viral-poc.ts` (novo no commit `ee8cb4f03`), o exemplo de uso do cabeçalho usa `:` como separador de par:

`scripts/apply-viral-poc.ts:7-8`
```
 *   npx tsx scripts/apply-viral-poc.ts --pairs "in0.json:scored0.json,in1.json:scored1.json" \
```

mas `parsePair` (`scripts/apply-viral-poc.ts:70-76`) só aceita `|`:

```ts
export function parsePair(pair: string): [string, string] {
  const parts = pair.split("|");
  if (parts.length !== 2 || !parts[0] || !parts[1]) throw new Error(`par inválido "${pair}" ...`);
```

Quem seguir o exemplo documentado recebe `par inválido` e o script aborta — em um POC que já é operado à mão (não está ligado a nenhum stage), a docstring É a interface.

Segundo ponto, menor, no mesmo arquivo: a mensagem de `--help`/erro de uso em `main()` (`:85`) também escreve `--pairs in:scored[,in:scored]`, com o mesmo separador errado.

## Correção esperada
Alinhar cabeçalho + mensagem de uso ao separador real (`|`), ou aceitar ambos em `parsePair`. Teste de `parsePair` cobrindo a forma documentada.
